Vineflower is a modern, general-purpose Java & JVM language decompiler focused on accuracy, output quality, and developer usability. It is a fork of JetBrains' Fernflower decompiler, building on the work of ForgeFlower, FabricMC's Fernflower fork, and Quiltflower — with significant enhancements for Java 21+ language features, multi-threaded decompilation, and an extensible plugin system.

## What Vineflower Does

Vineflower translates compiled JVM bytecode back into readable Java (and other JVM language) source. It handles the full range of modern Java constructs — records, sealed classes, switch expressions, pattern matching, and more — and produces consistently formatted output suitable for code review, analysis, or archival.

## Get Started

<Steps>
  <Step title="Download the JAR">
    Grab the latest `vineflower.jar` from [GitHub Releases](https://github.com/Vineflower/vineflower/releases) or add the Maven dependency to your build.
  </Step>
  <Step title="Decompile a file">
    Run the decompiler from the command line:
    ```bash
    java -jar vineflower.jar MyApp.jar ./decompiled/
    ```
  </Step>
  <Step title="Explore the output">
    Open the `./decompiled/` directory to browse the reconstructed source files.
  </Step>
  <Step title="Tune the options">
    Adjust [decompiler options](/usage/options) to control formatting, feature recovery, and more.
  </Step>
</Steps>

## Heritage

Vineflower stands on the shoulders of several prior projects:

| Project | Role |
|---|---|
| JetBrains Fernflower | Original decompiler — Apache 2.0 |
| MinecraftForge ForgeFlower | Community fixes and improvements |
| FabricMC Fernflower | Further accuracy improvements |
| Quiltflower | Significant quality and API enhancements |
| **Vineflower** | **Current active fork — modern Java, plugin API, clean output** |
